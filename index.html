Mini Urban Farming Project

An indoor farm with a Node-RED control dashboard and a Python camera app that checks plant leaves. I'm improving both the control side and the vision side.

  • Fixed Node-RED issues: LED 3 not turning on, the water pump and leak sensor, and incorrect main LED power behaviour.
  • Improved the Python code, which uses a model to detect plant leaves.
  • Added a calibration system for colour detection, covering colour masking, white balancing and leaf detection.
  • Built HSV scroll bars so the colour detection can be tuned live.

Autonomous Navigation in Unknown Factory Environments

An autonomous navigation system for a simulated factory, built with ROS 2 and a TurtleBot.

  • Designed and created a simulated factory layout in Gazebo to represent an unknown indoor environment.
  • Developed Python code to control the TurtleBot and navigate autonomously to specified locations.
  • Implemented Cartographer SLAM so the robot can map and localise itself in the environment.
  • Used Nav2 for path planning and navigation between designated locations.
  • Implemented navigation behaviour that adapts the path when the robot meets walls and unexpected obstacles.
  • Used RViz2 to visualise the map, robot position, navigation and sensor data during testing and debugging.
